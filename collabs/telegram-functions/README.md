# Telegram Collab Room — настройка в Windows

**Важно:** для живой работы бота нужен сервер. Код готов для Firebase Cloud Functions (2-го поколения), но его нужно развернуть в вашем Firebase-проекте самостоятельно. Для Cloud Functions требуется тариф **Blaze и платёжный аккаунт**. Небольшая нагрузка может укладываться в бесплатные квоты, но нулевые расходы не гарантируются. Рекомендуется бюджетное оповещение Google Cloud Billing.

**Никому не отправляйте токен бота**, включая чат, GitHub, Firestore и скриншоты. Он вводится только в локальной консоли и в Secret Manager.

## 1. Подготовка Firebase

- https://console.firebase.google.com/ → проект xwaran-collab-room
- Если Firebase на Spark, переключиться на Blaze и создать бюджетное оповещение
- Firestore Database → Rules → заменить правила **полным файлом** https://github.com/Gilbertum/streamerskaya/blob/main/collabs/firestore.rules → Publish
- Старые коллекции и пользователей не удалять, Test Mode не включать

## 2. Инструменты Windows

Установить Node.js 22 LTS и Git. В PowerShell:

    npm install -g firebase-tools
    firebase login
    git clone https://github.com/Gilbertum/streamerskaya.git
    cd streamerskaya/collabs/telegram-functions
    npm install
    firebase use xwaran-collab-room

Если репозиторий уже скачан, достаточно открыть папку collabs/telegram-functions и выполнить npm install.

## 3. Безопасные секреты

В PowerShell последовательно:

    firebase functions:secrets:set TELEGRAM_BOT_TOKEN

Вставить **готовый** токен от BotFather в запрос Firebase. Затем придумать отдельную случайную строку из 32–64 букв и цифр, записать её в менеджер паролей и выполнить:

    firebase functions:secrets:set TELEGRAM_WEBHOOK_SECRET

Вставить эту случайную строку. Она не должна совпадать с токеном бота.

## 4. Публикация функций и webhook

    firebase deploy --only functions

Firebase выведет URL функции telegramWebhook. Скопировать полный HTTPS URL, затем выполнить:

    node setup-webhook.mjs

Скрипт попросит (1) токен бота, (2) тот же TELEGRAM_WEBHOOK_SECRET, (3) URL telegramWebhook. Всё вводится **только в локальной консоли**. Секреты скрипт не сохраняет в файлы. Он зарегистрирует Telegram webhook с заголовком безопасности.

**Один бот может иметь только один webhook**. Если у этого бота уже есть другой сервис, настройка перехватит его входящие сообщения. Для Collab Room предпочтителен отдельный бот.

## 5. Привязка каждого стримера

1. На сайте открыть Профиль → Telegram-бот Collab Room → Подключить Telegram.
2. Нажать Привязать личный Telegram → перейти по выданной ссылке → нажать Start в личном чате бота. Код действует 15 минут.
3. Повторно открыть настройки Telegram на сайте; должен появиться статус подключения.
4. Добавить бота администратором **публичного Telegram-канала** с правом публиковать сообщения.
5. Указать канал в форме как @channel и нажать Проверить и подключить. Сервер проверит, что бот имеет право писать и что личный Telegram владельца — администратор именно этого канала.

## 6. Возможности

- Новое личное приглашение: игра, дата, время и кнопки Принять / Отклонить / Проверить расписание.
- Принять: бот повторно проверяет занятость участников и только потом ставит одну подтверждённую бронь. При выборе из нескольких вариантов или переносе он попросит открыть сайт.
- Отклонить: меняет статус именно этого приглашения, существующие коллабы не отменяются.
- Проверить расписание: присылает события на указанную дату **в личный чат**, не в публичный канал.
- Групповые приглашения: бот оповещает всех подключённых участниц. Для одной даты «Принять» отправляет согласие организатору; при нескольких датах требуется выбрать варианты на сайте.
- Кнопка Отправить обновлённое расписание в ТГ: после подтверждения публикует от имени подключённого канала текст:
  
  Расписание обновилось! Смотреть по ссылке: https://gilbertum.github.io/streamerskaya/collabs/#/s/ВАШ_UID
  
- Между публикациями действует пауза 60 секунд. Само изменение расписания не отправляет анонс без нажатия владельца.

## 7. Контрольный тест

1. Двум участницам привязать личные Telegram и сделать одно тестовое приглашение.
2. Проверить получение, кнопку Проверить расписание и кнопку Принять.
3. Сверить один подтверждённый коллаб в календаре обеих участниц.
4. Отправить второе приглашение на занятое время: бот обязан отказать.
5. Проверить кнопку Отклонить на отдельной заявке.
6. Сначала подключить тестовый Telegram-канал и отправить одно сообщение. После проверки можно указать рабочий канал.
7. Если что-то не работает: Firebase Console → Functions → Logs. Не публиковать токены в скриншотах.

## Ограничения

- Без развёрнутых Cloud Functions сайт продолжает работать, но Telegram-кнопки укажут, что сервер недоступен.
- Гости, добавленные вручную без кабинета Collab Room, не получают приглашения от бота.
- Скрытые личные отметки не публикуются автоматически.
- Привязка Telegram и конфигурация канала хранятся в закрытых серверных коллекциях, доступных только функциям.
- Для отключения публикаций можно удалить бота из администраторов канала. Для полного отключения также удалить вебхук и развернутые функции с учётом других пользователей.
